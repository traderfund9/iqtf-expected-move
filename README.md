# IQTF - Expected Move v4

Real-time Expected Move calculator using Twelve Data API.

## Features
- Real-time price quote (60s refresh)
- Expected Move (1H / 4H / 1D) via log-normal model
- HV(14) & sample SD calculation
- Price Standard Deviation ranges (±1/2/3 SD)
- NY session countdown
- Trade Level Engine (Entry/TP1/TP2/SL)

## Usage
1. เปิดเว็บ
2. ใส่ Twelve Data API Key (ฟรีที่ https://twelvedata.com)
3. เลือก Symbol + Timeframe
4. กดโหลด
